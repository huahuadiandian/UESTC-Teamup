## 1. 数据来源

本站竞赛信息主要来源于以下**公开渠道**：

- **各竞赛官方网站**：竞赛简章、报名通知、赛程安排等公开页面；
- **国内各高校竞赛组织部门发布的公开通知**：含校内选拔、报名等公开信息。

## 2. 整理与维护方式

本站将上述公开信息整理为**结构化的竞赛档案**（含届次年份、级别、时间线、推免加分认定等），并通过以下方式持续维护：

- **自动化采集**：对来源站点的公开页面进行定期监测与解析，发现新增或变更的竞赛与时间节点后入库更新；
- **人工核验**：级别、推免加分认定等关键字段，由维护团队比对官方文件后录入与校正；
- **用户纠错**：全站同学均可通过竞赛详情页的「纠错」入口按字段提交修正；被采纳的纠错会记录为贡献者，并**锁定对应字段**，防止被后续更新覆盖；
- **版本留痕**：竞赛字段的变更均进入版本记录，可追溯、可回滚。

## 3. 准确性声明

- 自动化采集可能存在**延迟、遗漏或解析错误**，本站不保证信息与官方渠道完全同步；
- **报名截止、赛程安排等关键信息，请务必以竞赛主办方的官方通知为准**；
- 推免加分等认定信息仅为整理与提示，具体认定以当年学校、学院的正式文件与政策为准；
- 本站展示的摘要与链接均指向原发布渠道，相关信息的著作权归原发布单位所有。

## 4. 版权与来源站点权益

- 本站以**信息聚合与校内公益**为目的整理展示公开信息，不用于商业用途；
- 若你是某来源站点的管理者，不希望本站收录贵站内容，或希望调整收录方式、更正信息，请通过下方渠道联系我们，我们将在核实后尽快**移除或调整**。

## 5. 联系我们
