## 这是什么

**UESTC TeamUp（成电人的竞赛罗盘）** 是面向电子科技大学在校学生的**竞赛信息聚合与组队平台**，由学生自发搭建、纯公益运营，与学校官方部门无隶属关系。

它针对两个具体的校园痛点：一是竞赛信息散落在官网、公众号与群聊各处，靠口口相传容易错过报名截止（DDL）；二是论坛式组队帖容易沉底、状态不透明、匹配效率低。本站希望把「找比赛」与「找队友」两件事，放进同一个平台解决。

## 主要功能

### 竞赛雷达

- **结构化竞赛档案**：按「届次年份」为每个竞赛建档，涵盖级别（国际 / 国家 / 省 / 校）、报名与赛程时间线、主办方、官网等关键信息，并支持历史届次切换查看；
- **推免加分认定**：单独标注「是否计入推免加分」及认定类别，并提供「只看能加分的比赛」一键筛选；
- **竞赛日历**：以日历视图呈现全年关键节点，报名期与赛程期分区显示，可一键订阅（.ics）到手机日历；
- **搜索与关注**：支持竞赛名 / 别名模糊搜索，关注竞赛后即可接收报名截止提醒。

### 队友招募

- **广告牌式组队广场**：以结构化招募卡替代论坛盖楼，卡片展示竞赛、目标、缺口方向、招募截止等要素，状态一目了然；
- **队伍状态清晰**：分为「招募中 / 已满员 / 已参赛 / 已解散」，公开列表只展示「招募中」的帖子，避免僵尸帖；
- **组队意愿机制**：联系方式默认遮挡，点击「我想组队」登记意愿后解锁，招募人可看到有多少人有意向，双方沟通更有针对性；
- **站内留言**：可在竞赛详情页与队伍详情页留言讨论。

### 提醒与通知

- 对关注的竞赛，在报名截止前 7 / 3 / 1 天推送**站内提醒**；
- 组队意愿、留言回复、纠错处理等关键动作，均通过站内消息通知。

## 谁在做

本站由**两名计算机学院的本科生**利用课余时间搭建与维护，**纯公益性质**——不收费、无商业广告、不做任何数据买卖。本站**与电子科技大学官方部门无关**，所有信息仅供校内同学参考，不构成任何官方承诺。
