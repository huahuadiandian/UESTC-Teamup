# 信息采集思路

## 思路一：固定脚本监听
设计服务器脚本监听各个竞赛官网/学校官网

- **缺点**： 
- 不同竞赛官网差异巨大，部分官网获取信息困难；
- 服务器开销较大

## 思路二：网页端ai搜集
设计本地自动化脚本，操控deepseek或其他网页端AI完成各竞赛的信息采集，通过提示词限制输出json，最后发送服务器

- **缺点**：ai幻觉or信息源不稳定
- **优点**：开销较小

## 思路三：联系科协等学科组织

当前网站的权限分为三种：“管理者”、“贡献者”、“普通用户”
“贡献者”是为科协等学科组织或热心人士预留，拥有修改竞赛信息的权限

可以联系数模协会、信通科协等组织，与他们合作
这些组织负责更新相关竞赛的信息、咨询、经验；
Teamup网站则担有宣传推广这些组织的义务。

以数模协会为例子：如果成功合作，他们将委派专人或轮流负责美赛、数模国赛、校赛、各类数学建模竞赛的信息同步。

对于一个学生组织来说，这些工作量并不算大

- **优点**：信息源准确，极大减轻信息收集压力，若合作良好将能扩大网站影响力

- **缺点**：不可能覆盖全部竞赛；且沟通成本较高


## 第一版构想：

- **1.同时采纳三种思路，将不同竞赛分类处理；**
- **2.实现保研加分竞赛的信息全收集与动态更新**
